# Ferry_Management_System
A college project where I designed a ferry management system

## About
- a college project where I crated a ferry management system that records vehicles boarding a ferry
- the vehicles would then exit the ferry in reverse order using a LIFO stack
- can record vehicle details
- details can be searched

  ## Features
  - add, and remove vehicles from the stack
  - record vehicle details such as number of passengers, vehicle type, etc
  - details can be searched through
 
  ## Technologies
  - C#
